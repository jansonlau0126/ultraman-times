# 18 隻怪獸 — 當初點畫？風格指引（文字版）

用途：畀畫師對齊現有 `mon_*.png` 風格；改圖／加攻擊幀／重畫窄怪都跟呢份。

---

## 1. 總風格（一句）

**Q 版（chibi）卡通怪獸插畫** — 大頭短身、圓潤可愛、顏色鮮艷、有元素特效光暈；像手機遊戲角色立繪，**唔係**寫實、唔係像素、唔係官方特攝照。

靈感：圓谷系怪獸「感覺」，但全部係同人原創造型（唔抄官方外型）。

同超人一致：同一套筆觸、同一夜城戰鬥場景用。

---

## 2. 比例同構圖

| 項目 | 規定 |
|------|------|
| 體型 | **大頭 40–50% 高度**，短四肢／圓身體 |
| 表情 | 大眼、可有腮紅；頭目可兇啲但仍 Q |
| 站姿 | 多數 **正面／¾ 面向鏡頭**，腳底落地 |
| 重心 | 角色置中，**腳底對齊畫布底**（遊戲 `object-position: bottom`） |
| 背景 | **全透明**（RGBA），唔好加地面／框 |
| 畫布 | 約 **360×360**（高約 360；寬 280–360 正常）。忌像虛幻魔咁窄（144px） |
| 留白 | 四周留少少透明邊，翼／爪／特效唔好貼死邊緣 |

---

## 3. 上色同線條

- **粗清線稿**（深色描邊，約中等粗幼），唔使超寫實毛孔
- **賽璐璐／軟梯度上色**：固有色 → 受光亮面 → 暗部；可有一點高光
- **元素特效要畫入圖**：火苗、閃電、冰晶、毒霧、影煙、星塵（圍繞身體，唔好淨係平色塊）
- 光感：**鮮艷、對小朋友吸引**；暗怪（黑龍、忍者貓）都要有亮眼／高光，唔好死黑一團
- 唔用：寫實皮紋、恐怖血腥、過於複雜機械零件堆砌

### 元素色感覺

| 元素 | 主調 | 特效 |
|------|------|------|
| fire | 橙紅／熔岩 | 火焰、火花 |
| ice | 青綠／冰藍 | 水晶、霜氣 |
| thunder | 藍白＋電黃 | 閃電弧 |
| poison | 黃砂／毒綠 | 霧、泡 |
| rock | 灰石／金屬 | 裂紋、鋸齒 |
| shadow | 黑紫／銀灰 | 煙、光核、星點 |

## 5. 情緒分級（仍然全部 Q 版）

- **夥伴味／可愛**（可腮紅）：天輝聖龜、雷神戰狼、幻影鬼貓、銀河飛蛾、深淵海王  
- **普通敵**：其餘多數  
- **頭目氣場**（更大、更兇眼、但唔恐怖）：鋼鐵暴君、虛幻魔、星辰霸王  

---

## 6. 技術交貨

- 格式：PNG，透明底  
- 命名：`mon_{id}.png`（攻擊幀：`mon_{id}_attack.png`）  
- 建議畫布：**360×360** 或高度 360、寬度讓角色飽滿（目標寬約 **300–360**）  
- 對照現有核准圖：`assets/battle/mon_*.png`（用戶已「全部用」）

---

## 7. 唔好做

- 寫實特攝怪、血腥內臟  
- 完全唔同筆觸（例如忽然變成像素或黏土）  
- 加實心底／外框／文字水印  
- 角色裁太窄、頭尾貼邊被切  
- 同超人風格脫節（超人已係銀紅 Q 版戰鬥立繪）
