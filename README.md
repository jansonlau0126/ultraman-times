# 超人乘數表

俾二年班小朋友同**超人奧米加**一齊打怪獸、學乘數表！答啱乘數題就可以出招，一路打低怪獸、一路記熟 1 至 10 嘅乘數表，喺 iPad、手機同電腦瀏覽器都玩得。

**https://jansonlau0126.github.io/ultraman-times/**

## 玩法

- **學習模式**：逐個乘數表睇、聽傳統九因歌口訣（如／得／歸／中）；學完成個表會記低進度同攞銅勳章。
- **打怪獸**：答啱就出招，連續答啱會出更勁嘅招式；可以揀自己打數字或者多項選擇。每場 5 關：三隻 Q 版怪獸 → 中頭目 → 最終大頭目**星辰霸主**。答錯時怪獸會放出專屬反擊圖。
- **除法戰鬥**：主頁另外一條路。題目係除得盡嘅除法（例如 24 ÷ 3），四個答案掣。一星除以 2、5、10；二星再加 3 同 4；三星除以 6 至 9，商可以去到 12，會打到滅世黑龍同星辰霸主。
- **計時挑戰**：60 秒內答得幾多題就幾多題（出招動畫期間時計會暫停，公平啲）。
- **戰績**：主頁大金掣入去。上面係分數同連擊，下面先係勳章、乘數表地圖同**怪獸圖鑑**——18 隻 Q 版怪獸有出沒／威力／稀有，撳「睇完整資料」睇完整介紹。未打低嘅會係黑影。

## 超人奧米加（Q 版最終定稿）

銀頭、青光大眼、額寶石、藍圓形計時器；連擊推進**五段變身**：

1. **銀光形態**（0）— 素銀原型  
2. **紅銀覺醒**（1–2）— 紅紋＋金領  
3. **藍披流星**（3–4）— 藍紋＋藍披風，**超級十字死光**  
4. **金焰超能**（5）— 金披風＋金焰氣場，**彩虹旋風斬**  
5. **奧米加翼光**（6+）— 青光翼＋金光環，**奧米加星煌爆**（傷害 28）  

答錯時，隻怪獸嘅屬性會打落條題目同四個答案掣上面（大約一秒），例如火、冰、雷、毒、岩、沙、鋼、水、暗、光、星。正確嗰個答案保持清楚，成個畫面唔會亂搖。圖鑑每隻有立繪同出招，並標住屬性。打低星辰霸主且連擊 ≥6 時，播**電影結局**（黑邊慢鏡）。計時挑戰都會變身，但只出短招。

## 招式

- 普通輪替：**十字死光**、**光速飛踢**、光輪斬、**爆裂光拳**、**螺旋旋風拳**、**彗星迴旋踢**
- 連擊 3：**超級十字死光**（藍披流星）
- 連擊 5：**彩虹旋風斬**（金焰超能）
- 連擊 6：**奧米加星煌爆**（奧米加翼光，傷害 28）
- 計時挑戰只用短招；答錯時每隻怪獸有專屬反擊招式名

## 開發

遊戲係單一檔案 `index.html`，由 `src/` 入面嘅 `style.css`、`body.html`、`art.js`、`game.js` 組成。改完 `src/` 之後執行：

```bash
python3 build.py
```
