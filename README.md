# 運算超人

俾小學低年級同**超人奧米加**一齊打怪獸、學運算！主頁叫「運算超人」。學習係乘數表；打怪有七個模式。答啱就出招，連擊會變身。喺手機直向、iPad 同電腦瀏覽器都玩得。

## 玩法

- **學習・乘數表**：逐個乘數表睇、聽傳統九因歌口訣（如／得／歸／中）。學完可以即刻用嗰個表去打「乘法火焰爆」。
- **打怪（主頁七個掣，一場打完）**：加法大進擊、減法暗影戰、加減雙刃斬、乘法火焰爆、除法冰封關、乘除雷電擊、四則終極戰。平常要答啱 15 題先打低；大約一成機會遇到現有 18 隻入面嘅頭目，就再加 5 至 8 題。答錯唔會完場，怪獸會反擊，之後可以繼續。連擊變身同之前一樣（大約連對 6 題先到奧米加翼光，答錯會跌形態）。
- **四則終極戰**：有加減乘除一步題，亦有由左到右嘅兩步題（例如 3×4+2），答案一個數就得。
- **圖鑑收藏**：開現有 18 隻怪獸圖鑑。**戰績**淨係戰績，唔再連去圖鑑。

## 超人奧米加（Q 版最終定稿）

銀頭、青光大眼、額寶石、藍圓形計時器；連擊推進**五段變身**：

1. **銀光形態**（0）— 素銀原型  
2. **紅銀覺醒**（1–2）— 紅紋＋金領  
3. **藍披流星**（3–4）— 藍紋＋藍披風，**超級十字死光**  
4. **金焰超能**（5）— 金披風＋金焰氣場，**彩虹旋風斬**  
5. **奧米加翼光**（6+）— 青光翼＋金光環，**奧米加星煌爆**（傷害 28）  

答錯時，隻怪獸嘅屬性會打落條題目同四個答案掣上面（大約一秒），彈出「火！」呢類大字。正確嗰個答案保持清楚，成個畫面唔會亂搖。答案掣平時係純數字。圖鑑每隻有立繪同出招，並標住屬性。打低星辰霸主且連擊 ≥6 時，播**電影結局**（黑邊慢鏡）。限時同連擊挑戰都會變身，但只出短招。

## 招式

- 普通輪替：**十字死光**、**光速飛踢**、光輪斬、**爆裂光拳**、**螺旋旋風拳**、**彗星迴旋踢**
- 連擊 3：**超級十字死光**（藍披流星）
- 連擊 5：**彩虹旋風斬**（金焰超能）
- 連擊 6：**奧米加星煌爆**（奧米加翼光，傷害 28）
- 計時挑戰只用短招；答錯時每隻怪獸有專屬反擊招式名

## 開發

遊戲係單一檔案 `index.html`，由 `src/` 入面嘅 `style.css`、`body.html`、`art.js`、`game.js` 組成。改完 `src/` 之後執行：

```bash
python3 build.py
```

然後用瀏覽器開 `index.html`（唔使伺服器都得）。手機畫面請用直向。
