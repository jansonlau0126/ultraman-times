# 超人乘數表

俾二年班小朋友同**超人奧米加**一齊打怪獸、學乘數表！答啱乘數題就可以出招，一路打低怪獸、一路記熟 1 至 10 嘅乘數表，喺 iPad、手機同電腦瀏覽器都玩得。

## 玩法

- **學習模式**：逐個乘數表睇、聽傳統九因歌口訣（如／得／歸／中）；學完成個表會記低進度同攞銅勳章。
- **打怪獸**：答啱就出招，連續答啱會出更勁嘅招式；可以揀自己打數字或者多項選擇。每場 5 關：三隻怪獸 → 中頭目 → 最終大頭目**星辰霸王**。
- **計時挑戰**：60 秒內答得幾多題就幾多題（出招動畫期間時計會暫停，公平啲）。
- **我的進度**：乘數表地圖、要多啲練習嘅題目、勳章、金幣，仲有**怪獸圖鑑**——打敗過嘅怪獸就會由黑影變成彩色；撳開圖鑑卡會放大怪獸，儲齊 18 隻！

## 超人奧米加（Q 版最終定稿）

銀頭、青光大眼、額寶石、藍圓形計時器；連擊推進**五段變身**：

1. **銀光形態**（0）— 素銀原型  
2. **紅銀覺醒**（1–2）— 紅紋＋金領  
3. **藍披流星**（3–4）— 藍紋＋藍披風，**超級十字死光**  
4. **金焰超能**（5）— 金披風＋金焰氣場，**彩虹旋風斬**  
5. **奧米加翼光**（6+）— 青光翼＋金光環，**奧米加星煌爆**（傷害 28）  

頭目關、第 4 關起，或連擊 ≥7 時，答題板會出現屬性**畫面擾亂**。打低星辰霸王且連擊 ≥6 時，播**電影結局**（黑邊慢鏡）。計時挑戰都會變身，但只出短招。

## 招式

- 普通輪替：**十字死光**、**光速飛踢**、光輪斬、**爆裂光拳**、**螺旋旋風拳**、**彗星迴旋踢**
- 連擊 3：**超級十字死光**（藍披流星）
- 連擊 5：**彩虹旋風斬**（金焰超能）
- 連擊 6：**奧米加星煌爆**（奧米加翼光，傷害 28）
- 計時挑戰只用短招；答錯時每隻怪獸有專屬反擊招式名

## 開發

遊戲係單一檔案 `index.html`，由 `src/` 入面嘅 `style.css`、`body.html`、`art.js`、`game.js` 組成。改完 `src/` 之後執行：

```bash
python3 build.py
```
